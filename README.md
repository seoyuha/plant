# 🌻 Garden Road Defense — 정원으로 가는 길을 막아라!

6학년 영어 9단원 **How Can I Get to the Museum?** 복습 게임이에요.
좀비들이 정원으로 가는 길을 찾아 몰려와요. 모둠 친구들과 영어 문제를 맞혀 ☀️ 태양을 모으고,
식물을 심어 정원을 지켜요. (그림은 원래 게임 파일의 식물·좀비 스프라이트를 그대로 사용해요.)

- 학생 주소: `https://내주소/`
- 교사 주소: `https://내주소/teacher`

## 들어 있는 것
```
package.json
server.js        ← 게임 서버 (Node.js 기본 기능만 사용, 설치할 것 없음)
questions.js     ← 9단원 문제 103개
public/
  index.html     ← 학생 화면
  teacher.html   ← 교사 화면
  assets/        ← 원래 게임의 그림 (식물·좀비 6프레임 스프라이트, 로비 그림)
test/sim.js      ← 봇 학생으로 한 판 돌려 보는 점검 도구
```

## 문제 구성 (9단원 지도서 기반, 103문제)
| 분류 | 개수 | 예 |
|---|---|---|
| 단어 | 38 | "between"의 뜻은? / "박물관"을 영어로 하면? |
| 그림 보고 말하기 | 10 | 🚌 3번 버스 ➜ 🏛️ 박물관에서 내리기 → Take Bus Number 3 and get off at the museum. |
| 길 묻기 | 8 | 🦁 동물원 가는 방법 묻기 → How can I get to the zoo? |
| 위치 표현 | 10 | 🏦 ⭐ 🏫 → It's between the bank and the school. |
| 빈칸 채우기 | 15 | Take ___ 3 and get off… → Bus Number (a/the 쓰지 않기) |
| 대화 | 5 | 잘 못 들었을 때 → Sorry? |
| 읽기 | 8 | Sally's Travel, Job Land, Star Library 지문 |
| 철자 | 9 | library / libary / liberary … |

- 학생마다 문제 순서가 다르고, 보기 순서도 매번 섞여요.
- 틀린 문제는 3문제 뒤에 다시 나와요. 틀리면 3초 동안 다음 문제를 풀 수 없어서 아무거나 누르기를 막아요.
- 문제를 고치려면 `questions.js`를 열어 고치면 돼요 (정답을 보기의 맨 앞에 적어요).

## 게임 규칙
- 정답 1개 = ☀️ 태양 50. 시작 전에도 문제를 풀어 태양을 모아 둘 수 있어요.
- 식물: 🌻태양꽃(태양 생산 50) · 🌱완두콩(공격 100) · 🪵방어벽(벽 50) · 🌵선인장(강한 공격 125) · 🍄얼음버섯(느리게 150) · 🌶️불꽃고추(범위 공격 175)
- 🧹 뽑기: 심은 식물을 뽑으면 태양 절반을 돌려받아요.
- 좀비 공격 6번(웨이브)을 막으면 성공, 좀비가 정원에 5마리 들어오면 실패예요.

## 교사 화면에서 할 수 있는 것
- 반 만들기: 모둠 수(1~8)를 고르면 모둠 방이 한 번에 만들어지고 **반 코드 4자리**가 나와요. 한 모둠은 최대 6명.
- 👀 모둠 현황: 모둠마다 웨이브·생명·태양, 학생별 접속과 정답률. 모둠별 / 전체 시작·멈춤·새 판.
- 🧒 학생별: 맞힘·틀림·정답률·최근 틀린 문제
- 📊 문제 분석: 정답률 낮은 문제부터, 많이 고른 오답, 틀린 학생, 분류별 정답률
- 📺 큰 화면: TV에 띄우는 반 코드와 모둠 순위
- 📥 결과 내보내기: 엑셀에서 열리는 CSV (학생별 요약 · 문제별 정답률 · 전체 풀이 기록)
- 📁 문제 바꾸기(선택): 다른 문제를 CSV로 올릴 수 있어요. 첫 줄 `문제,보기1,보기2,보기3,보기4,정답번호`

## 학생들에게 배포하는 방법

### 방법 A. 인터넷에 올리기 (Render, 추천)
학생들이 학교 와이파이든 집이든 주소만 치면 들어올 수 있어요. 윷놀이 게임과 같은 방법이에요.

1. **GitHub에 올리기**
   - github.com → New repository → 이름 예: `garden-road` → Create
   - "uploading an existing file"을 누르고, 압축을 푼 폴더 안의 파일과 폴더를 **끌어다 놓기**로 올려요.
     (`public` 폴더는 끌어다 놓아야 폴더째 올라가요.)
   - 저장소 첫 화면에 `package.json`, `server.js`, `questions.js`, `public/`이 보이면 성공.
2. **Render에서 배포하기**
   - render.com → New → **Web Service** → 방금 만든 저장소 선택
   - Language: **Node** · Build Command: `npm install` · Start Command: `npm start` · Instance Type: **Free**
   - Create Web Service → 2~3분 뒤 `https://garden-road-xxxx.onrender.com` 같은 주소가 생겨요.
3. **수업에서**
   - 수업 시작 **5분 전에 교사 화면(`/teacher`)을 먼저 열어** 서버를 깨워 두세요. (무료 서버는 15분 동안 아무도 안 쓰면 잠들고, 깨는 데 30초~1분 걸려요.)
   - 반 만들기 → 📺 큰 화면 탭을 TV에 띄우고 주소와 반 코드를 알려 줘요.
   - 학생: 주소 접속 → 반 코드 → 모둠 고르기 → 이름 → 출발
   - 다들 들어오면 **▶ 모두 시작**. 한 판은 약 5~7분이에요. (좀비 공격 6번)
   - 수업이 끝나면 📥 결과 내보내기로 기록을 저장해 두세요.

> ⚠️ 무료 서버가 잠들거나 다시 시작되면 반과 기록이 지워져요. 수업 중에는 잠들지 않으니 걱정 없고,
> 기록은 수업이 끝날 때 꼭 내보내기로 저장해 두세요. (다음 시간에는 새 반을 만들면 돼요.)

### 방법 B. 교실 컴퓨터에서 바로 열기 (인터넷 없이, 같은 와이파이)
1. 교사 컴퓨터에 Node.js(18 이상)를 설치해요. (nodejs.org → LTS)
2. 압축을 푼 폴더에서 주소창에 `cmd` 입력 → `node server.js`
3. 교사: `http://localhost:3000/teacher`
4. 학생: `http://교사컴퓨터IP:3000` (IP는 cmd에서 `ipconfig` → IPv4 주소)
   - 윈도우 방화벽이 물어보면 "허용"을 눌러요. 학교 와이파이가 기기끼리 연결을 막으면 방법 A를 써요.

### 혼자 연습
반 코드 없이 학생 화면의 **혼자 연습하기**로 집에서도 연습할 수 있어요. (기록은 교사에게 가지 않아요.)

## 점검 기록
- 교사 1명 + 학생 여러 명(태블릿·휴대폰 크기)으로 브라우저에서 입장 → 문제 풀이 → 배치 → 멈춤 → 새로고침 이어하기 → 결과 내보내기 확인
- 봇 학생 모둠으로 실제 시간 한 판씩 돌려 난이도 확인 (`node test/sim.js 3000 5 0.75`)
