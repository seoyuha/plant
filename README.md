# 과학 정원 지키기 — 시안 연결판

초등학교 3학년 과학(지구와 바다) 5단계 40문제 식물 디펜스 게임입니다.

## 이번 버전
- 상단 가로 스크롤 카드 덱, 나무 재질 HUD, 중앙 5×9 전투장으로 재배치
- 개별 식물/좀비 애니메이션 이미지와 기존 융합 시스템 그대로 연결
- 가로 화면/태블릿/전체화면에서 보이는 높이 자동 제한
- 5개 단원 배경과 과학 문제, 점수/기록 저장 유지
- assets/design_reference.png는 디자인 참고 시안이며 게임의 캐릭터 스프라이트로 사용하지 않습니다. 캐릭터는 별도의 투명 PNG 애니메이션을 사용합니다.

## 배포
ZIP을 풀고 내용 전체(index.html, questions.json, assets, .nojekyll)를 GitHub Pages 저장소 루트에 업로드하세요.
