# ⚔️ 정원으로 가는 길을 막아라! — 친구와 대결판 (6학년 영어 9단원)

혼자 하던 정원 디펜스 게임에 **학생끼리 좀비 보내기 대결**을 더한 서버 버전이에요.
화면·그림·식물·문제(9단원 60문제)는 혼자 하기 버전과 똑같아요.

- 학생 주소: `https://내주소/`  → ⚔️ 친구와 대결 (혼자 모험도 그대로 할 수 있어요)
- 교사 주소: `https://내주소/teacher`

## 대결 규칙
- 2~4명이 한 방. 2명이면 1:1, 3~4명이면 마지막까지 살아남기.
- 각자 **자기 정원**을 지켜요. 기본 좀비는 천천히 오고, 시간이 갈수록 빨라져요.
- **문제를 맞히면 ☀️ +50, 그리고 친구 정원에 🧟 좀비 1마리**가 가요. (친구가 여럿이면 좀비를 가장 적게 받은 친구에게)
- **3문제 연속 정답**이면 🪣 양동이 좀비를 보내요. 친구가 보낸 좀비는 보라빛으로 빛나요.
- 틀리면 ☀️ +15를 받지만 **3초 동안 문제를 풀 수 없어요** (아무거나 누르기 방지).
- 대결 중에는 멈출 수 없어요. 문제 창을 여는 동안에도 좀비가 절반 속도로 와요.
- 목숨 5개를 모두 잃으면 탈락. 마지막까지 남은 정원이 1등. **6분**이 지나면 목숨 → 정답 수로 순위.
- 끝나면 방장(👑)이 🔁 한 판 더 → 같은 친구들과 다시.

## 🔑 교사 비밀번호
교사 화면(`/teacher`)은 비밀번호로 잠겨 있어서 학생들은 들어갈 수 없어요. (학생 게임 화면은 비밀번호 없이 그대로)

**방법 1. Render 환경 변수로 정하기 (추천, 한 번 정하면 계속 그대로)**
1. Render에서 내 서비스(garden-battle) → 왼쪽 **Environment** → **Add Environment Variable**
2. Key: `TEACHER_PASSWORD` · Value: 원하는 비밀번호 → **Save Changes**
3. 서버가 1~2분 동안 다시 시작되면 끝. 이제 교사 화면에서 이 비밀번호를 써요.

**방법 2. 교사 화면에서 처음 한 번 정하기**
방법 1을 하지 않았다면, 교사 화면에 처음 들어갈 때 비밀번호를 정하는 창이 나와요.
다만 무료 Render 서버는 잠들었다 깨거나 새로 배포되면 이 비밀번호가 지워져서, 그때마다 다시 정해야 해요.
(그 사이에 다른 사람이 먼저 정할 수도 있으니 방법 1을 추천해요.)

- "이 기기에서 기억하기"를 켜 두면 그 기기에서는 다음부터 비밀번호를 묻지 않아요. 🔒 잠그기를 누르면 잊어요.
- 비밀번호를 5번 틀리면 1분 동안 막혀요.
- 비밀번호를 바꾸려면: 방법 1은 Render에서 값 수정, 방법 2는 교사 화면 📖 수업 안내 탭 아래에서 바꿔요.

## 수업 흐름
1. 학생: 주소 접속 → **⚔️ 친구와 대결** → 이름 쓰기
2. 한 명이 **방 만들기**(문제 범위: 전체 섞기 또는 1~5단계) → 화면의 **방 번호 4자리**를 짝에게 알려 줘요.
3. 짝은 방 번호를 넣고 **들어가기** → 방장이 **▶ 대결 시작**
4. 교사 화면(`/teacher`)에서 모든 방의 진행 상황(목숨·정답·오답·보낸 좀비)을 실시간으로 봐요.
5. **🏅 오늘의 기록** 탭: 학생별 판 수·1등 횟수·정답률. **📥 CSV**로 내려받아 엑셀에서 열 수 있어요.

## 배포하는 방법 (Render, 무료)
윷놀이·정원 지키기 서버 버전과 같은 방법이에요.

1. **GitHub에 올리기**
   - github.com → New repository → 이름 예: `garden-battle` → Create
   - "uploading an existing file"을 누르고, 압축을 푼 폴더 안의 `package.json`, `server.js`, `public` 폴더를 **끌어다 놓기** → Commit
2. **Render에서 배포하기**
   - render.com → New → **Web Service** → 방금 만든 저장소 선택
   - Language: **Node** · Build Command: `npm install` · Start Command: `npm start` · Instance Type: **Free**
   - 2~3분 뒤 `https://garden-battle-xxxx.onrender.com` 같은 주소가 생겨요.
3. **수업 5분 전에 교사 화면을 먼저 열어** 서버를 깨워 두세요. (무료 서버는 15분 동안 안 쓰면 잠들고, 깨는 데 30초~1분 걸려요.)

### 교실 컴퓨터에서 바로 (같은 와이파이)
Node.js(18 이상) 설치 → 폴더에서 `node server.js` → 교사 `http://localhost:3000/teacher`, 학생 `http://교사컴퓨터IP:3000`

> ⚠️ 서버가 잠들거나 다시 시작되면 방과 기록이 지워져요. 수업이 끝나면 기록을 CSV로 내려받아 두세요.
> ⚠️ 대결 중에 새로고침하면 그 판은 탈락이에요. (대기실에서는 새로고침해도 같은 방으로 다시 들어가요.)
